# Assignment 2: Training System Student & Course Management

## Problem Statement & Requirements
You are developing a system for a training system to keep track of students and the courses they are enrolled in. The system has two main requirements:

* **Manage Student Enrollments:** Each student can register for multiple courses.
* **Efficient Retrieval & Analytics:** The system must be able to quickly retrieve all courses for a specific student and determine which student is enrolled in the highest number of courses.

Design and implement a Java solution that efficiently handles this requirement.

---

## Concepts Used
* **Java Collections Framework**
* **Object-Oriented Design (OOD)** (Classes, Attributes, and Relationships)
* **Efficient Lookups & Data Aggregation** (Using appropriate data structures like `HashSet` and maps/lists for tracking counts)
