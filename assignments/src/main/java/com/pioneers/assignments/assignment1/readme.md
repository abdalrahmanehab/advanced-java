# Assignment 1: Library Book Loan System

##  Problem Statement & Requirements
You are developing a system for a library to manage book loans. The library has two types of operations:
* **Add a new book loan:** When a book is loaned out, its ID is added to the system.
* **Return a book:** When a book is returned, its ID is removed from the system.

The library wants to keep track of all book loans in the order they were added and handle book returns efficiently.

Implement a system using Java collections that allows for:
1. **Adding** the ID of a loaned book.
2. **Removing** the ID of a returned book and **printing** all current loaned book IDs in the order they were loaned out.

---

##  Concepts Used
* **Java Collections Framework**
* **Insertion-Order Preservation** (Maintaining the order of loans)
* **Efficient Lookup & Removal**
